# Spendly

Spendly is a minimal Flutter expense tracking app prototype aligned with the supplied PRD.

## Included in this implementation

- Onboarding screen with the Spendly brand and “Get Started”.
- Dashboard with monthly total, trend placeholder, and recent transactions.
- Add Expense flow with amount/category/date/note and save action.
- Analytics screen with distribution placeholder and key metrics.
- Calendar screen with monthly view and day transactions list.
- Settings screen for currency, monthly budget, dark mode toggle, and data options.

## Tech notes

- Flutter + Dart
- Project prepared for Riverpod, Hive, fl_chart, and google_mobile_ads integration.
- Minimal starter architecture with `lib/features`, `lib/models`, and `lib/core` directories.
